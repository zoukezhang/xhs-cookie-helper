# 小红书 Cookie 助手 (XHS Cookie Helper)

这是一个简单的 Chrome 浏览器扩展，用于快速提取并复制小红书 (xiaohongshu.com) 的 Cookie 信息。

## 功能特点

- **一键获取**: 自动识别并提取小红书域名的所有 Cookie。
- **智能复制**: 支持一键复制 Cookie 字符串，方便粘贴使用。
- **状态检测**: 自动检测是否已登录小红书账号。
- **安全隐私**: 代码开源，仅在本地运行，不上传任何数据。

## 安装说明

1. 下载本仓库代码到本地。
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`。
3. 开启右上角的 "开发者模式"。
4. 点击 "加载已解压的扩展程序"，选择本项目的根目录。

## 使用方法

1. 确保已在 Chrome 浏览器中登录 [小红书官网](https://www.xiaohongshu.com/)。
2. 点击浏览器右上角的插件图标。
3. 点击 "获取 Cookie" 按钮。
4. 点击 "一键复制" 按钮即可将 Cookie 复制到剪贴板。

## 注意事项

- 本插件仅供个人学习和开发调试使用。
- 请妥善保管您的 Cookie 信息，切勿发送给他人，以免账号被盗。
